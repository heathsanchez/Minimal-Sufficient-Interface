# The Difference Test

A deliberately tiny executable witness for the representation-forcing core of consequential distinction.

## What the four-state core establishes

Let the old interface identify states according to the first coordinate and let the old action flip only that coordinate. A verifier-certified residual distinguishes two states merged by the old interface. The experiment then checks:

1. the residual pair is merged by the old interface;
2. every action in the complete old finite closure preserves that observational identification;
3. the residual endpoints and old dynamics generate a new orbit separator without supplying the target feature identity;
4. combining the separator with the old observation produces a lawful refinement;
5. exact ablation restores the old identification.

The 24 state permutations test **presentation equivariance only**. They rule out dependence on one literal state numbering. They are not claimed as domain transfer.

## Factorization sanity check

The test enumerates every Boolean map out of the old quotient and confirms that the sealed target is absent. This is an executable sanity check of the factorization obstruction:

\[
\forall h:R_0\to\{0,1\},\qquad h\circ\pi_0\neq f.
\]

It is **not independent empirical evidence against search failure**. Because the residual is defined by a pair with `pi_0(x)=pi_0(y)` and `f(x) != f(y)`, non-factorization follows immediately. The enumeration guards the implementation; the mathematical content is the factorization theorem itself.

## Uniqueness boundary

The original 2+2 four-state witness has a unique coarsest lawful refinement. That uniqueness is local to its geometry and must not be generalized.

The same test file now includes a separate four-state `3+1` world in which one residual has **two incomparable coarsest lawful repairs**, both strictly coarser than the discrete partition:

\[
\{\{0\},\{1,2\},\{3\}\},
\qquad
\{\{0,2\},\{1\},\{3\}\}.
\]

The two repairs disagree on a concrete pair, so the live version space itself determines a discriminating next experiment. This is the appropriate witness for the set-valued repair claim

\[
\rho\mapsto\mathcal V(\rho),
\]

not the unique-repair base world.

## Transfer boundary

A further check applies the same residual-orbit constructor at carrier sizes four and six with different action-closure orders. This is stronger than pure relabeling, but it is intentionally called **cross-cardinality structural transfer**, not domain transfer.

Evidence for nonliteral developmental transfer lives in stronger experiments elsewhere in the repository:

- `tests/test_recursive_developmental_compounding.py` compiles verified source residual history into an anonymous query policy. Source and target query identities are disjoint. Under a matched one-query target budget, WARM alone reaches the exact target MSI and makes the downstream action quotient-admissible; COLD, RAW_HISTORY, SHAM and exact ABLATION fail.
- `tests/test_golden_law_meta_becoming.py` learns a behavioural constructor class from source failures, transfers it to disjoint target operator identities, and shows a promoted generator enables a second unseen recursive composition; cold depth-1 and exact ablation fail.
- `tests/test_blind_recursive_cross_grammar_genesis.py` tests independently specified grammars, sealed held-out behaviour, controls, ablation and recursive promotion.

These are still finite synthetic domains. They support source-distinct structural transfer; they do not by themselves establish unrestricted natural-domain transfer.

## What remains genuinely stronger

The representation-forcing core is not the whole developmental claim. The strongest single-chain experiment would still combine, in one precommitted world:

\[
\text{certified residual}
\to
\text{old-closure obstruction}
\to
\text{generated new distinction/operator}
\to
\text{new executable capability}
\to
\text{exact ablation}
\to
\text{source-distinct reuse}
\to
\text{changed later development}.
\]

The repository already contains separate witnesses for every later arrow. The next scientific compression is to make those arrows occur in one minimal causal chain without weakening their controls.
