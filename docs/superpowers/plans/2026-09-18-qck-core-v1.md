# QCK Core v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Formalize the canonical context-stable quotient, its induced dynamics, all-word substitution theorem, and universal/coarsest sufficient-linear-representation property in Lean.

**Architecture:** Keep the existing Std-only MSI files unchanged. Add a self-contained pinned Mathlib subproject under `qcklean/`. `QCKCore.lean` is basis-free and quotient-first; `QCKCoreTest.lean` is a compile-time interface test. A dedicated workflow checks the pinned project independently.

**Tech Stack:** Lean 4 `v4.35.0-rc2`; Mathlib commit `44ba35c6daa9d69aff8fed9fff9bbde17ded774d`; GitHub Actions Ubuntu 24.04.

**Spec:** `docs/superpowers/specs/2026-09-18-qck-core-v1-design.md`

## Global Constraints
- QCK-Core is basis-free and does not define matrices or costs.
- The action alphabet is shared between source and replacement in v1.
- The semantic core does not depend on PSD, inner products, probability, or finite-dimensional rank calculations.
- No theorem claims nonlinear or universal operational minimality.
- Existing MSI files and workflows remain behaviorally untouched.
