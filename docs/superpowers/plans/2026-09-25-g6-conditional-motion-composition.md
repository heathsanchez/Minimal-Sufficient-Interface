# G6 Conditional Motion Composition Plan

## Scientific claim

Test the conditional interface earned from exact G3–G5 supervision:

- non-stationary target columns are determined by primitive motion alone;
- stationary events require the already-observed endpoint/source-port refinements;
- every G6 event is non-stationary, five cardinal events are directly supervised, and the sole diagonal event is the only residual;
- test only OR, AND, and XOR composition of the two supervised cardinal column meanings for that diagonal event.

This differs from the rejected global event-pair Boolean family because five G6 columns are held fixed by solved cross-level supervision and Boolean composition is applied only to the one unseen diagonal primitive.

## Gate

1. Add pure tests for the conditional motion codebook, exact five-of-six G6 coverage, diagonal factorization, fail-closed behavior, bounded candidate enumeration, and replay policy.
2. Implement an independent experiment script importing the qualified observation/replay machinery without rewriting earlier evidence.
3. Add a branch-scoped hosted workflow against the exact public environment.
4. Run the complete regression suite locally.
5. Publish the exact branch, run the hosted gate, retain every attempted diagonal law, and update ROS with exact authority.

## Promotion and residual boundaries

- **PROMOTED:** one diagonal law advances G6 and replays exactly twice.
- **WARRANTED_NEGATIVE:** all three earned diagonal compositions fail while the five directly supervised columns remain fixed.
- **EXACT_RESIDUAL:** supervision is non-functional, G6 differs from the declared five-cardinal/one-diagonal census, or a required cardinal meaning is absent; zero writes.
- **NON_EVIDENCE:** harness, validation, or replay failure.
