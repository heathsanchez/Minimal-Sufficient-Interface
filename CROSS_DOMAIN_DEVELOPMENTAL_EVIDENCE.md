# Cross-domain developmental evidence

The MSI kernel is intentionally domain-neutral. Its core claim is not that one particular representation, operator or policy should transfer everywhere. It is that verified futures determine which distinctions and constructions are justified, and that retained developmental products can change later reachable capability.

The strongest evidence now spans four levels with different claim boundaries.

## 1. Controlled finite mechanism — recursive compounding

The repository's direct finite witness establishes

\[
\boxed{
\text{development}_1
\to
\text{retained developmental policy}
\to
\text{development}_2.
}
\]

A source episode returns only verifier-certified residual pairs. Those residuals are compressed into an anonymous structural query policy. On a source-distinct target with disjoint literal query identities and a frozen one-query budget, WARM reaches the exact target MSI while COLD, RAW_HISTORY, SHAM and ANCESTOR_ABLATION fail.

See [`RECURSIVE_DEVELOPMENTAL_COMPOUNDING.md`](RECURSIVE_DEVELOPMENTAL_COMPOUNDING.md).

This closes the recursive causal arrow in the controlled finite setting.

## 2. Arithmetic — representation and dependency structure

The arithmetic sequence moves beyond abstract finite carriers.

Verified causal conflicts reject most-significant-first local addition, residuals recover the required positional precedence chain, and only then does MSI discover the two-state latent interface needed for exact local composition. The same two-state behavioural structure is independently recovered across positional bases 2 through 16, and the frozen transducer extrapolates well beyond the discovery length.

The strongest structural result is that, for widths 2, 3, 10, 32 and 128, exactly `n-1` verifier counterexamples recover

\[
\boxed{0\to1\to\cdots\to n-1}.
\]

See [`ARITHMETIC_REPRESENTATION_GENESIS.md`](ARITHMETIC_REPRESENTATION_GENESIS.md).

This establishes domain-level **representation development**: verified failures alter both the dependency structure of composition and the latent state carried across the resulting interfaces.

## 3. Formal theorem proving — source-distinct verified compounding

A separate Lean/Vero experiment supplies the strongest current source-distinct external-verifier causal result.

The source theorem family independently verifies a reusable lower-level convolution-scaling substrate:

1. modular scalar transport;
2. scaling through padded list addition;
3. left-scaling through convolution.

The later source-distinct target is two-sided scaling through the higher-level `gfMul` operation. Under a frozen budget of four **new** support groups:

| arm | target verified |
|---|---:|
| WARM retained verified substrate | **yes** |
| COLD | no |
| RAW_HISTORY | no |
| SHAM | no |
| ANCESTOR_ABLATION | no |

The decisive external run is `heathsanchez/test` Actions run `33149206252`.

Thus, for source development `D₁`, retained Lean-certified substrate `K₁`, target development `D₂`, and budget `B=4`,

\[
\boxed{
\operatorname{VerifyReach}_B(D_2+K_1)=\mathrm{true}
}
\]

while the matched cold, raw, sham and exact-ablation arms remain false.

This is **capability/discovery compounding inside a supplied Lean proof language**. It does not establish new Lean syntax, tactic invention or new syntactic formability.

## 4. ARC — strong within-episode development, unresolved cross-episode identity

The ARC-AGI sequence provides a useful counterweight because it separates what does and does not transfer.

Inside frozen ARC episodes, verified future collisions forced a cumulative heterogeneous observation basis. Later, a residual-history policy changed subsequent question selection: the learned history policy reached the exact protected future quotient on all four frozen tasks, including one task the memoryless residual policy could not close under the same eight-query budget.

So ARC establishes

\[
\boxed{
\rho_t
\to
H_t
\to
q_{t+1}
}
\]

inside an episode, where `H_t` is retained verifier-returned residual history rather than a supplied semantic concept.

Prospective cross-episode tests then exposed a real boundary rather than a clean positive result:

- a global source query-shape prior did not dominate on source-distinct ARC tasks;
- allowing the prior to override live target residuals was actively harmful;
- making it defeasible recovered some performance, but RAW and SHAM controls reproduced the apparent gain, so the learned source prior still lacked causal identity.

The resulting constraint is:

\[
\boxed{
\text{current verified residual evidence}
\succ
\text{inherited developmental prior}.
}
\]

A prior may break ties among futures still equivalent under current evidence; it may not override a distinction the current verifier has already forced.

The ARC evidence therefore supports within-episode developmental policy formation, but broad source-distinct policy transfer should not yet be promoted as established.

## What joins the domains

The domains do **not** retain the same object:

- arithmetic retains a causal precedence relation and a minimal latent interface;
- finite MSI can retain an anonymous query policy;
- Lean retains verified reusable proof substrate;
- ARC retains a cumulative observation basis and residual history, while the correct cross-task transferable abstraction remains unresolved.

What transfers across domains is the developmental law:

\[
\boxed{
\text{PUSH}
\to
\text{VERIFIED FAILURE}
\to
\text{RESIDUAL}
\to
\text{JUSTIFIED DISTINCTION OR CONSTRUCTION}
\to
\text{RETAIN}
\to
\text{CHANGED FUTURE REACH / SEARCH}.
}
\]

The strongest warranted cross-domain statement is therefore:

\[
\boxed{
\textbf{Verified developmental products can become causal substrate for later development,}
}
\]

with an essential qualification:

\[
\boxed{
\textbf{the form of the transferable product is domain- and residual-relative.}
}
\]

This is stronger and more falsifiable than asserting that one universal learned feature, query prior or representation should transfer unchanged.

## Evidence hierarchy

The current promotion boundary is:

1. **Finite mechanism:** recursive developmental causality — established.
2. **Concrete computation:** verifier-forced structural and latent representation development in arithmetic — established.
3. **External formal verifier:** source-distinct retained proof substrate causally enlarges the later verified proof frontier — established.
4. **Natural visual reasoning:** residual history changes later within-episode development — established; source-distinct transferable policy identity — not yet established.
5. **Open-ended generative self-development:** not established.

The remaining frontier is therefore not another proof that quotients refine. It is to discover, from raw natural residuals, which developmental object is itself stable enough to transfer without overriding current evidence.
