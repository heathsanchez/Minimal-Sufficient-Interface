# MSI capstone gap closure — 2026-08-29

This note records what changed after `DEVELOPMENTAL_REGIME_GENESIS_CAPSTONE.md` identified four remaining arrows.

## 1. Unique minimal justified refinement — CLOSED formally

`lean/MinimalRepair.lean` proves the universal property that was previously implicit in the meet kernel.

For the induced refinement order

\[
x \preceq y \iff x \wedge y = x,
\]

the update

\[
\boxed{E' = E \wedge K}
\]

refines both the prior interface `E` and the verified constraint `K`, and every state that refines both `E` and `K` also refines `E'`.

Therefore `E ∧ K` is the greatest lower bound in the refinement order: equivalently, the **coarsest / least-change state satisfying both requirements**. Lean also proves uniqueness of any object satisfying this universal property.

This closes the relation-level form of

\[
\boxed{\text{verified constraint} \to \text{unique minimal justified refinement}.}
\]

It does not say that an arbitrary residual uniquely determines one concrete program, constructor or morphism. Program-level uniqueness remains quotient-relative: different implementations may realize the same minimal behavioural repair.

## 2. Minimal generated regime extension — CLOSED formally

`lean/GeneratedStage.lean` defines `adjoinStage S f`, the closure generated by:

1. every continuation already accessible in stage `S`;
2. one newly verifier-licensed morphism `f`;
3. identities;
4. everything forced by composition.

Lean proves the universal property:

> Any composition-closed stage extending `S` and admitting `f` must contain every morphism in `adjoinStage S f`.

Thus `adjoinStage S f` is the **least composition-closed regime extension** containing the new morphism.

The same file joins this to `DevelopmentalCategory.new_separator_forces_split`: if `f` separates a pair merged by the old stage, then adjoining exactly this least generated extension forces a strict behavioural-interface refinement.

This closes the formal arrow

\[
\boxed{
\text{licensed morphism}
\to
\text{least generated regime extension}
\to
\text{strict quotient refinement}.
}
\]

Together with the existing bounded endogenous-genesis experiments, the programme now has the two halves of residual-driven regime change in explicit form:

\[
\rho \to f
\quad\text{(bounded exhaustive synthesis)}
\]

and

\[
f \to \operatorname{Adjoin}(S,f) \to Q_{t+1}
\quad\text{(general Lean theorem)}.
\]

The remaining theorem-level bridge is to internalize residual-to-`f` selection at the same abstraction level, ideally only up to behavioural equivalence rather than literal syntax.

## 3. Observation-language genesis — CLOSED under the bounded generated-language protocol

`tests/test_observation_language_genesis.py` moves the uncertainty boundary above a fixed observation atom.

The initial interface contains only one observation. The learner receives no target observation identity. Instead it receives verifier-returned collision pairs and generates candidate observations from a grammar of primitive state bits, negation, conjunction and xor.

A candidate is admitted only when it repairs every live verifier collision, introduces no distinction not licensed by the verifier-required target quotient, genuinely refines the old interface, and is minimal in the generated observation language.

The focused CI census covers every binary verifier distinction on the four-state carrier for which the initial interface has a live residual:

- `live_worlds = 12`;
- `recovered = 12`;
- `exact_kernel = 12`;
- `ablation_failures = 12`;
- `generated_extensional_atoms = 16`.

Thus the bounded chain

\[
\boxed{
\rho
\to
\text{generated observation atom}
\to
\Pi_{t+1}
}
\]

is established under the frozen generated-language protocol.

This is stronger than selecting among supplied semantic observation names, but weaker than discovering the verifier's protected objective, human intent, or a raw natural observation vocabulary without a generative substrate.

## 4. Categorical emergence — one-object case supported; multi-object/type genesis remains open

The repo already contains a one-object categorical precursor:

- `CONSTRUCTOR_GENESIS.md` generates a composition term from syntax rather than a named law;
- verifier counterexamples eliminate alternatives;
- retained composition has zero identity-law failures and zero associativity failures on the exhaustive finite census;
- `BehaviouralCongruence` and `TypedBehaviouralCongruence` establish quotient-compatible composition and functorial descent.

Thus composition law can be operationally recovered rather than named, and the recovered operation satisfies the axioms of a one-object category (a monoid) on the reachable algebra.

What is **not** yet closed is the stronger multi-object claim

\[
\boxed{
\text{residual development}
\to
\text{emergent object/type boundaries + typed homs + identities + composition}
}
\]

without those object/type boundaries being installed in advance.

That is now the sharp categorical frontier.
