# Counterexample-Driven Constructor Law Discovery

This experiment asks the next stronger question:

> Can verifier counterexamples select the correct composition law itself, rather than merely discovering useful composites under a supplied constructor?

The answer is yes up to the exact operational notion MSI should care about: counterexamples identify sequential composition whenever the reachable world distinguishes it, and otherwise leave only constructor laws that are extensionally equivalent on the reachable subalgebra and therefore induce the same reachable closure and behavioural quotient.

## Setup

The hidden environment uses true sequential composition

\[
(f\circ g)(x)=f(g(x)).
\]

The learner is **not told** that this is the correct constructor. Instead it begins with a small version space of six typed binary constructor hypotheses on deterministic state transformations:

- sequential composition `seq`;
- reversed composition `rev`;
- left projection;
- right projection;
- pointwise minimum;
- pointwise maximum.

For each finite world, the verifier may return a constructor counterexample

\[
(f,g,x,y)
\]

meaning that executing `g` then `f` on state `x` actually yields `y`. Any constructor hypothesis predicting a different result is eliminated.

The learner is not given a composition table, a generated monoid, or the final behavioural quotient.

## Exhaustive census

We exhaust all

- 8 binary observations on three states;
- 27 deterministic choices for primitive `g0`;
- 27 deterministic choices for primitive `g1`;
- **5,832 total worlds**.

Results:

- **4,704** worlds uniquely identify sequential composition;
- **1,128** worlds remain syntactically ambiguous;
- **0** worlds contain harmful ambiguity;
- **20,472** verifier counterexamples are used across the census;
- at most **4** counterexamples are needed in any world.

The surviving-version-space histogram is:

- `('seq',)` — 4,704 worlds;
- `('seq','rev')` — 800 worlds;
- `('seq','rev','min')` — 160 worlds;
- `('seq','rev','max')` — 160 worlds;
- all six constructors — 8 degenerate worlds.

## The important result

In every one of the 1,128 ambiguous worlds, every surviving constructor is extensionally identical to true sequential composition **on the reachable subalgebra generated by the primitives**.

Consequently every survivor generates exactly the same reachable transformations and the same behavioural quotient as the hidden true constructor.

So the verifier does not force a syntactic name for composition when the world itself supplies no counterexample that can distinguish the alternatives.

That is not a failure. It is the MSI principle applied one level higher:

\[
\boxed{
\text{do not preserve a distinction between constructor laws unless reachable behaviour earns it.}
}
\]

The strongest safe statement is therefore:

\[
\boxed{
\textbf{Counterexamples recover the composition law up to operational equivalence on the reachable action algebra.}
}
\]

Equivalently:

\[
\boxed{
\textbf{The system learns exactly as much compositional structure as future behaviour can justify.}
}
\]

## Why this matters

The previous experiment assumed a generic sequential constructor and learned which composite programs mattered. This experiment moves the uncertainty outward: composition itself is now a hypothesis.

The resulting developmental ladder is

\[
\text{constructor hypotheses}
\to
\text{verifier counterexamples}
\to
\text{version-space contraction}
\to
\text{reachable action algebra}
\to
\text{behavioural quotient}.
\]

When the world distinguishes the true constructor, the wrong laws are eliminated. When it does not, the remaining laws are operationally indistinguishable and induce the same MSI.

## Boundary

This is still a bounded hypothesis-family experiment. The six candidate constructors are supplied in advance, and the verifier can evaluate actual sequential execution on reachable transformations. The system is therefore selecting/identifying a composition law from counterexamples, not inventing arbitrary algebraic operations from an unbounded language.

The next stronger target is **constructor genesis**: generate candidate typed composition operators from a grammar, use verifier residuals to retain only those that earn predictive/compositional value, and test whether associative identity-preserving structure emerges without listing the candidate laws by hand.
