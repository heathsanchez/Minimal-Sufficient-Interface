# Bounded grammar-genesis experiment

This is a deliberately finite follow-up to the verified OpenDevelopment arithmetic baseline. It tests a different limitation: a target-blind learner must acquire a missing binary operator rather than select another predeclared recurrence. It is not a claim of unrestricted development or general cross-domain transfer.

The initial language has two Boolean inputs, constants, and unary NOT. Programs are acyclic circuits with at most four gates. The trusted fixture requests NAND (truth-table mask 7), then holds out XOR (mask 6). The learner receives only the acquisition oracle and does not receive target names or the held-out table. The repair interface permits a new operator of arity at most two; the complete four-row table determines the selected operator. This finite table is not an arbitrary unknown semantic grammar.

The learner exhaustively checks the old language, infers the missing arity and table, and installs a certificate only after the trusted oracle accepts all four rows. A separate checker replays the actual circuits and rejects malformed dependencies, altered tables, identities, and outputs. The acquired operator solves NAND in one gate and the held-out XOR in four gates. Removing it leaves only unary Boolean functions, which cannot compute either target. The Lean development proves the stronger old-language obstruction for every unary circuit, not merely the four-gate enumeration, and checks the two concrete circuits on every Boolean input.

The proof template is fixed and the mathematical target fixture is trusted. Python does not prove its own controller correct, and the certificate hash is an identity, not an authentication mechanism. The qualification binds the existing OpenDevelopment source hash, regenerates the Lean file, checks byte-for-byte equality, independently replays the result, and compiles with the repository's pinned Lean 4.24.0 toolchain. The exact commit, run, job and internal output determine the final status. A green workflow is not evidence for stronger claims than these checks.
